# HCiHY Brand System — 20-Document Map

Full enterprise brand systems (Apple HIG, Stripe, IBM, Fluent) are built as a set of independent-but-cross-referencing documents. This is the target set for HCiHY. Build them roughly in this order — later docs lean on earlier ones.

## Phase 1–3: Foundation (build first, everything else depends on these)
1. **Brand Bible** — mission, vision, values, purpose, brand story, brand promise, elevator pitch, customer promise, personality, voice, tone, messaging, UVP, audience, competitive positioning, brand philosophy.
2. **Logo Standards Manual** — primary/secondary logo, icon-only, horizontal/vertical, wordmark, monochrome (black/white), embroidery, laser engraving, watermark, min/max size, safe area, improper usage, background rules, placement rules.
3. **Color System** — primary/secondary/accent colors, semantic colors (success/warning/danger/info), dark mode, light mode, glass/chrome colors, gradient library, background/card/button colors, hover/focus states, glow effects; HEX/RGB/HSL/CSS vars; accessibility compliance.
4. **Typography Guide** — headline/body/display/code fonts + fallbacks, weights, line heights, letter spacing, paragraph spacing, button type, captions, tables, lists, accessibility.

## Phase 4: Visual Identity detail
5. **Spacing System** — grid, columns, margins, padding, border/corner radius, shadow system, elevation levels, icon sizes, image ratios, whitespace rules.
6. **Iconography Guide** — stroke weight, rounded vs. sharp, perspective, animation, approved icon sets, custom icons.
7. **Photography Guide** — lighting, color grading, people/expressions/wardrobe, environments, backgrounds, composition, lenses, mood, depth of field, negative examples.
8. **Illustration Guide** — shapes, gradients, materials (glass/chrome), line art, abstract shapes, connection motifs.

## Phase 5: Design System
9. **Website Design System** — nav, hero, CTA, cards, pricing, FAQ, timeline, feature grid, testimonials, buttons, inputs, forms, modals, tables, alerts, badges, pagination, footer, header, search, loading states, 404, animations.

## Phase 6: Marketing Assets
10. **Marketing Guide** — messaging, campaign structure, landing pages, email marketing, sales copy, CTAs, social posts, SEO tone, ad style, presentation style.
11. **Social Media Guide** — templates for LinkedIn, Facebook, Instagram, Threads, TikTok, YouTube, Pinterest, podcast covers, story templates, reels, carousels, thumbnail style.
12. **Brand Asset Package** — business card, letterhead, envelope, invoice, proposal, deck/PowerPoint, email signature, Zoom background, t-shirt, hat, mug, laptop sticker, vehicle graphics, trade show booth, roll-up banner.
13. **Motion Guide** — logo animation, loading animation, hover animation, transitions, video intro/outro, motion speed, easing, timing, micro-animations.
14. **Writing Guide** — grammar, sentence length, reading level, formatting, capitalization, headlines, bullets, CTAs, technical writing, blog posts, docs, emails, support responses, social posts, website copy.

## Phase 7: AI Documentation
15. **AI Image Generation Guide** — lighting, materials, lens, camera, composition, negative prompts, approved colors, rendering style, background style, humans, technology, brand mood.
16. **Prompt Engineering Guide** — reusable, brand-consistent prompts for ChatGPT, Claude, Gemini, Midjourney, Ideogram, Firefly, Canva AI, Sora, Cursor, GitHub Copilot.
17. **Developer Design Tokens** — JSON, CSS variables, Tailwind tokens, Figma variables, component naming standards.
18. **AI Brand Context** — one master file any AI ingests before starting work: mission, vision, voice, tone, colors, typography, logo rules, writing style, website style, coding style, marketing style, image style, brand philosophy, forbidden/approved styles.

## Phase 8–10: Implementation, Governance, Launch
19. **Brand Governance** — approval process, version control, brand change requests, asset naming, folder structure, who can modify brand assets, quality standards.
20. **Launch Checklist** — website, social, domain, email signatures, business cards, SEO, Google Business Profile, GitHub, LinkedIn, marketing materials, press release, internal docs, asset distribution, AI context updates.

## The 10 phases (for sequencing multi-document work)
Research → Strategy → Brand Foundation → Visual Identity → Design System → Marketing Assets → AI Documentation → Implementation → Quality Review → Final Approval.

## Definition of done
A brand system session isn't complete until: any future designer could follow the docs without asking questions, any developer could build from them, any AI model could generate on-brand work after reading Doc 18, and the brand feels unified across print, web, video, presentations, merch, social, and software.
